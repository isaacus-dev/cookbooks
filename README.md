# Isaacus Cookbooks
**Isaacus Cookbooks** are helpful guides showing how you can use Isaacus AI models in practice to solve real problems.

## Usage 👩‍💻
Our Cookbooks are stored in the [`cookbooks`](./cookbooks) directory. Each Cookbook is stored in its own folder. Inside each folder, you will find one or more Jupyter notebooks alongside a README file explaining what the Cookbook is about and how to run it.

Every Cookbook is self-contained and, therefore, you do not need to install any global dependencies to run them apart from Python and Jupyter. Cookbooks will install required dependencies for you.

## Issues 🚩
If you have any issues running an Isaacus Cookbook, please open an issue [here in our GitHub repository](https://github.com/isaacus-dev/cookbooks) and we will do our best to resolve it as soon as possible. You can also create issues to suggest new Cookbooks that you'd like to see added.
